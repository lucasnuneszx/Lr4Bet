# 🚀 Criando Repositório Privado no GitHub

## 📋 Passos para Criar o Repositório

### 1. Acesse o GitHub
- Vá para [github.com](https://github.com)
- Faça login na sua conta

### 2. Crie o Repositório
- Clique no botão **"New"** ou **"+"** no canto superior direito
- Escolha **"New repository"**

### 3. Configure o Repositório
```
Repository name: lr4.bet
Description: 🎰 Plataforma completa de cassino online e apostas esportivas
Visibility: Private ✅
Initialize this repository with: NÃO marque nenhuma opção
```

### 4. Clique em "Create repository"

## 🔗 Configurar Remote e Fazer Push

Após criar o repositório, execute estes comandos no terminal:

```bash
# Adicionar o remote origin
git remote add origin https://github.com/SEU_USUARIO/lr4.bet.git

# Verificar se foi adicionado
git remote -v

# Fazer push para o GitHub
git push -u origin main
```
